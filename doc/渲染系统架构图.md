## 渲染管线流程图

### 延迟渲染管线

```mermaid
graph TD
    Start[开始渲染] --> ShadowPass[阴影渲染]
    ShadowPass --> DirectionalShadow[方向光阴影]
    ShadowPass --> PointShadow[点光源阴影]
    
    DirectionalShadow --> MainPass[主相机通道]
    PointShadow --> MainPass
    
    MainPass --> GBuffer[G-Buffer渲染]
    GBuffer --> DeferredLighting[延迟光照]
    DeferredLighting --> ForwardLighting[前向光照]
    ForwardLighting --> ToneMapping[色调映射]
    ToneMapping --> ColorGrading[颜色分级]
    ColorGrading --> Vignette[暗角效果]
    Vignette --> FXAA{FXAA启用?}
    FXAA -->|是| FXAARender[FXAA抗锯齿]
    FXAA -->|否| UIRender[UI渲染]
    FXAARender --> UIRender
    UIRender --> CombineUI[UI合成]
    CombineUI --> End[渲染完成]
```

### 前向渲染管线

```mermaid
graph TD
    Start[开始渲染] --> ShadowPass[阴影渲染]
    ShadowPass --> DirectionalShadow[方向光阴影]
    ShadowPass --> PointShadow[点光源阴影]
    
    DirectionalShadow --> MainPass[主相机通道]
    PointShadow --> MainPass
    
    MainPass --> ForwardLighting[前向光照]
    ForwardLighting --> Skybox[天空盒渲染]
    Skybox --> Particle[粒子渲染]
    Particle --> ToneMapping[色调映射]
    ToneMapping --> ColorGrading[颜色分级]
    ColorGrading --> Vignette[暗角效果]
    Vignette --> FXAA{FXAA启用?}
    FXAA -->|是| FXAARender[FXAA抗锯齿]
    FXAA -->|否| Axis[坐标轴渲染]
    FXAARender --> Axis
    Axis --> UIRender[UI渲染]
    UIRender --> CombineUI[UI合成]
    CombineUI --> End[渲染完成]
```

## 主相机通道子通道流程

```mermaid
graph TD
    MainCameraStart[主相机通道开始] --> Subpass0[子通道0: BasePass]
    Subpass0 --> GBufferRender[G-Buffer渲染]
    GBufferRender --> Subpass1[子通道1: Deferred Lighting]
    Subpass1 --> DeferredLighting[延迟光照计算]
    DeferredLighting --> Subpass2[子通道2: Forward Lighting]
    Subpass2 --> ForwardLighting[前向光照渲染]
    ForwardLighting --> ParticleRender[粒子渲染]
    ParticleRender --> Subpass3[子通道3: Tone Mapping]
    Subpass3 --> ToneMapping[色调映射]
    ToneMapping --> Subpass4[子通道4: Color Grading]
    Subpass4 --> ColorGrading[颜色分级]
    ColorGrading --> Subpass5[子通道5: Vignette]
    Subpass5 --> Vignette[暗角效果]
    Vignette --> Subpass6[子通道6: FXAA]
    Subpass6 --> FXAA{FXAA启用?}
    FXAA -->|是| FXAARender[FXAA渲染]
    FXAA -->|否| Subpass7[子通道7: UI]
    FXAARender --> Subpass7
    Subpass7 --> UIRender[UI渲染]
    UIRender --> Subpass8[子通道8: Combine UI]
    Subpass8 --> CombineUI[UI合成]
    CombineUI --> MainCameraEnd[主相机通道结束]
```

## 渲染系统初始化流程

```mermaid
graph TD
    Start[引擎启动] --> InitGlobalContext[初始化全局上下文]
    InitGlobalContext --> CreateRenderSystem[创建渲染系统]
    CreateRenderSystem --> InitRHI[初始化RHI]
    InitRHI --> CreateVulkanRHI[创建VulkanRHI]
    CreateVulkanRHI --> LoadGlobalResources[加载全局资源]
    LoadGlobalResources --> CreateRenderCamera[创建渲染相机]
    CreateRenderCamera --> CreateRenderScene[创建渲染场景]
    CreateRenderScene --> CreateRenderResource[创建渲染资源]
    CreateRenderResource --> CreateRenderPipeline[创建渲染管线]
    CreateRenderPipeline --> InitRenderPasses[初始化渲染通道]
    InitRenderPasses --> SetupDescriptorSets[设置描述符集]
    SetupDescriptorSets --> CreateFramebuffers[创建帧缓冲区]
    CreateFramebuffers --> InitComplete[初始化完成]
```

## 每帧渲染流程

```mermaid
graph TD
    FrameStart[帧开始] --> ProcessSwapData[处理交换数据]
    ProcessSwapData --> PrepareContext[准备渲染上下文]
    PrepareContext --> UpdatePerFrameBuffer[更新每帧缓冲区]
    UpdatePerFrameBuffer --> UpdateVisibleObjects[更新可见对象]
    UpdateVisibleObjects --> PreparePassData[准备通道数据]
    PreparePassData --> UpdateDebugDraw[更新调试绘制]
    UpdateDebugDraw --> CheckPipelineType{检查管线类型}
    CheckPipelineType -->|前向| ForwardRender[前向渲染]
    CheckPipelineType -->|延迟| DeferredRender[延迟渲染]
    ForwardRender --> FrameEnd[帧结束]
    DeferredRender --> FrameEnd
```
